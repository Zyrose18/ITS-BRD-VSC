Was ist Git?:
Git ist ein Werkzeug zur Versionsverwaltung. Es hält Änderungen an meinen Projektdateien fest, sodass ich sie nachvollziehen und frühere gespeicherte Stände wiederherstellen kann.

Was ist GitHub?:
GitHub ist die Plattform wo du deinen Aktuellen code mit Versionshistorie speichern kannst.

Was bedeutet Lokal?:
Lokal bedeutet auf deinen Rechner. Der Code befindet sich auf deinen Rechner. dsa
